The rules for tic-tac-toe are as follows:
Grid: The game is played on a 3-by-3 grid. 
Players: Two players take turns marking the grid with X or O. 
Turns: Players alternate placing their marks in empty squares. 
Winning: The first player to get three marks in a row wins. The row can be horizontal, vertical, or diagonal. 
Tying: If all squares are filled and no player has three marks in a row, the game is a tie. 
Starting player: The player who plays X usually goes first. 
Strategy: A good strategy is to create a "fork", which means placing your mark so that you can win in two ways on your next turn.
